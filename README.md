# DawnAurora Player Animations Bedrock Add-On
Player animation overhaul add-on for Minecraft Bedrock Edition.

Current Version: v0.0.1 Alpha (Early Preview)
This build is stable for basic gameplay, reserved for iterative updates.

## Finished Content
Full core player animations. All items include custom 3D models.

## Planned Animations (Work in Progress)
- Sleeping animation
- Stretch animation
- Two-hand flourish animation

## Roadmap
- v0.0.1 Alpha: Current stable preview release
- Next Alpha versions: Add planned animations and polish details
- Beta: Further polish and bug cleanup
- Stable Release: Full complete release

## Installation
1. Download `.mcaddon` from Releases page.
2. Import into Minecraft Bedrock.
3. Activate both Resource Pack and Behavior Pack.
