# DawnAurora Players Animation Bedrock Add-On
Player animation overhaul add-on for Minecraft Bedrock Edition

## About
This add-on redesigns the player’s native animations for Bedrock Edition.
It aims to create smoother, more realistic movement, combat and interaction animations for the player entity.

Current Version: v0.0.1 Alpha (Early Preview)

> ⚠️ Alpha Preview Warning
This is an early test build. Many bugs remain.
Use only for testing and feedback. Not suitable for long-term worlds.

## Known Bugs
1. Swimming render issue: Arms become default Steve/Alex skin while swimming.
2. Multiple model clipping issues in animations (bones clip through body, armor and items).
3. First-person animation misalignment and unnatural hand poses.
4. Some animation state transitions are jerky or poorly timed.

## Roadmap
- v0.0.1 Alpha: Initial preview release, collect bug reports
- v0.0.2 Alpha: Fix swimming arm render bug, reduce clipping and fix first-person animation defects
- Beta phase: Clean up remaining animation glitches, polish animation transitions
- Stable Release: Full feature complete, major bugs resolved

## Installation
1. Download `.mcaddon` from Releases page.
2. Import into Minecraft Bedrock.
3. Activate both Resource Pack and Behavior Pack inside your world.
